بسته انتشار گالری NOCTURNE

۱) این پوشه را در ریشه یک مخزن عمومی GitHub بارگذاری کن.
۲) فقط فایل‌ها و پوشه‌های داخل این پوشه را بارگذاری کن، نه خود پوشه مادر را.
۳) در Settings → Pages، گزینه Deploy from a branch را انتخاب کن؛ Branch برابر main و Folder برابر / (root) باشد و Save بزن.
۴) این صفحه فقط نمونه‌کار هنری است؛ هیچ قابلیت فروش، پرداخت، اتصال کیف پول یا Mint ندارد.
۵) فقط تصاویر پیش‌نمایش کم‌حجم و واترمارک‌دار در این بسته قرار دارند؛ فایل‌های اصلی را در رایانه نگه دار.
