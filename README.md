# NOCTURNE — Relics of the Silent City

A personal digital-art portfolio preview featuring five AI-assisted gothic-surreal artworks.

This repository is a static portfolio only. It has no checkout, payment flow, wallet connection, minting function, or sales links. It is not an NFT marketplace.

## Publish with GitHub Pages

1. Create a **public** repository on a personal GitHub account.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Wait for the Pages deployment and open the generated `https://USERNAME.github.io/REPOSITORY/` address.

GitHub Pages on GitHub Free requires a public repository. Use this as a non-commercial artist portfolio only; GitHub says Pages must not be used as free hosting for an online business, e-commerce site, or website primarily facilitating commercial transactions. Do not add a checkout, wallet connection, mint widget, or sale links here.

## Files

- `index.html`: portfolio page
- `artworks/`: reduced-size, watermarked preview copies
- `branding/`: portfolio logo assets

High-resolution master files should remain in your private local archive and should not be uploaded to this public repository.
